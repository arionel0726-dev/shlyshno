## Статусы

У каждой карточки есть статус. Меняется на странице карточки или в композере:

| Статус        | Что значит                          |
| ------------- | ----------------------------------- |
| Новое         | Только поступило, ещё не смотрели   |
| Рассматриваем | Изучаем, обсуждаем                  |
| В плане       | Решили делать, ждёт очереди         |
| В работе      | Делаем прямо сейчас                 |
| Сделано       | Релизнули — подписчикам ушло письмо |
| Закрыто       | Не будем делать                     |

## Публичный роадмап

Страница `/p/ваш-проект/roadmap` показывает карточки колонками по статусам —
пользователи видят, что движется. Ссылка обновляется сама.

## Чейнджлог

Когда ставите статус «Сделано», все подписчики карточки получают письмо.
Отдельные записи чейнджлога публикуются из раздела **Changelog** — они
появляются на публичной странице `/p/ваш-проект/changelog`.

## Настройки проекта

В **Настройки → Бренд** можно поменять название и сайт, в **Домен** —
скопировать ссылку на доску. Свой домен — на тарифе Pro.
